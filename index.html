읽기 잠금

아이와 같이 읽을 때 켜요. 이전 · ▶ · 다음만 남아요. 전체화면은 되는 기기에서만 켜져요 — iPhone Safari나 다른 앱 속 화면에선 브라우저 메뉴가 그대로 보여요.

이 버튼은 화면 안 조작만 잠급니다. 홈 버튼·앱 전환은 기기 설정으로만 막을 수 있어요.

iPad에서 확실하게 — 사용법 유도
  1. 처음 한 번만: 설정 › 손쉬운 사용 › 사용법 유도 → 켬 → 암호 설정.
  2. 읽을 이야기를 연 채로 아래 잠그기를 누른다.
  3. 측면 버튼(홈 버튼이 있는 iPad는 홈 버튼)을 빠르게 세 번 → 화면 위쪽 Claude 메뉴 줄을 손가락으로 동그라미(그 자리 터치 막기) → 시작.
  4. 끝낼 때: 다시 세 번 → 암호 → 종료.

iPad 전체화면은 아래로 쓸면 풀리고, Claude 화면 안에서는 아예 막혀 있어요. 그래서 이 버튼만으로는 위쪽 메뉴를 못 숨겨요 — 사용법 유도는 기기가 막아 줘서 아이가 나갈 수 없어요.

해제 방법

오른쪽 위 🔒를 2.5초 길게 누른 뒤, 어른 확인(한 자리 덧셈)을 풀면 풀려요.

기기 자체 잠금(앱 전환까지 막으려면)
  • iPhone — 툴바 없이 보려면이야기 목록 화면(집 버튼) 위쪽 비행기 모양 ‘비행기 준비’에 나오는 ‘사운드북 앱’(홈 화면 아이콘으로 여는 앱)은 Safari 툴바가 없어요. 이 화면은 아래 사용법 유도로 잠가요. (이 화면을 .html 파일로 저장해 열면 Safari에서 움직이지 않아요.)
  • iPhone · iPad — 사용법 유도설정 › 손쉬운 사용 › 사용법 유도 켜고 암호 설정 → 이 화면에서 측면(홈) 버튼 세 번 → 시작. 해제 = 세 번 + 암호.
  • Android — 앱 고정설정 › 보안 및 개인정보 보호 › 기타 보안 설정 › 앱 고정 허용 → 최근 앱 버튼 → 앱 아이콘 → '이 앱 고정'. 해제 = 최근 앱 + 뒤로 가기 동시에 길게.
